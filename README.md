# godot_platformer

godot을 활용한 플랫포머 게임의 튜토리얼을 진행하였습니다. godot의 씬/ 노드/ 시그널 등 기초 시스템을 이용하는 법을 학습하였고, charactor animation, particle system등 이펙트 효과를 학습하였습니다. 또한 중력 코요테 점프 등 플랫포머 게임에서 기초가되는 게임시스템을 이해하게 되었습니다.
